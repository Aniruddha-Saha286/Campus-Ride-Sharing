Project Overview
Campus Ride Sharing is a platform that lets verified university students share rides with one another using their official university (GSuite) email for identity verification. Any student can post a ride offer or request to join one and the platform supports both one-time trips and daily recurring routes that automatically repeat without needing to be reposted each day. To protect user privacy, a rider's contact information and home area are only revealed to the other party after a seat request has been accepted.
Campus Ride Sharing is planned as a MERN-based web application. The platform includes a mock cost-splitting system, a mock live trip-status tracker, and a community trust score built from post-trip ratings, helping students commute together in a safer, more affordable, and more reliable way within the campus community.
